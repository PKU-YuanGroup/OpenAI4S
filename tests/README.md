# Tests

[中文说明](README_zh.md)

The offline correctness gate for OpenAI4S. `uv run pytest` runs every module here against deterministic fakes, and it has to stay green: the provider-neutral agent engine, the Host services, the persistent Python/R kernel protocol, the repositories, the security boundaries, the tools, the Skills, and the Web composition. Reusable scenarios and scored evaluations are a separate layer and live in [`../harness/`](../harness/).

## Offline contract

- `uv run pytest` must not need a live LLM, an API key, network, a GPU, an SSH host, a Docker daemon, a browser, or a lab system. [`conftest.py`](conftest.py) points `~/.openai4s` at a temporary directory for every test and installs a fake provider and key.
- A test that needs an external resource has to opt in through a marker registered in `pyproject.toml`; [`test_marker_policy.py`](test_marker_policy.py) guards that rule. The deselection is a mechanism rather than a habit: `addopts` carries `--strict-markers` and the "not external and not network and …" expression, so an unregistered marker is a collection error instead of a silent skip.
- A test that replaces a service with a stub must carry `stubbed_backend`. `scripts/capture_response_schemas.py` reruns this suite with a recorder installed and freezes what the routes returned into `docs/response-schemas.json`, whose entire claim is that it was captured from real responses; the marker pauses the recorder for the test's duration, and without it a fabricated body is published as that route's contract.
- Captured inputs and byte-sensitive samples live under `fixtures/`; tests must not silently rewrite them.
- Network, subprocess, provider, clock, UUID, and filesystem boundaries are mocked or confined. The only exception is a smoke program that says so and is invoked separately.
- Run one module with `uv run pytest tests/test_kernel.py`, one case with `uv run pytest tests/test_agent.py::test_max_turns_stop`, or the full gate with `uv run pytest`.
- `uv run pytest` is the floor, not the whole gate. The directory-README check, the harness `tier:pr` scenarios, both response captures, the source secret scan, the Linux private-PID interrupt smoke, and the browser suites are separate CI jobs that fail independently — [`test_ci_gate_independence.py`](test_ci_gate_independence.py) exists because four of them used to be steps *inside* another job, where an unrelated red test made them unreachable.

## Support and smoke files

| File | Responsibility |
| --- | --- |
| [`conftest.py`](conftest.py) | Sets up import paths, gives every test its own data directory, configures a fake LLM provider and key, cleans up the `Store` afterwards, and holds the shared pytest fixtures. It also pins the posture the suite is supposed to measure rather than inherit from whoever is running it: `OPENAI4S_UNATTENDED_APPROVAL=deny`, `OPENAI4S_SECRET_STORE=plaintext` (so no test writes to the developer's login keychain), `OPENAI4S_NOTEBOOK_REPL=0`, the share and MCP-deadline variables cleared out of any git-ignored `.env`, and the telemetry endpoint aimed at `https://127.0.0.1:1/` — not hypothetical hygiene, that one: a benchmark case granted consent to itself and really POSTed a fresh install id to the live endpoint from every developer machine and CI runner. | [`_ports.py`](_ports.py) | Race-free port allocation for the tests that bind a real gateway `ThreadingHTTPServer`. | [`browser_p1_controls.mjs`](browser_p1_controls.mjs) | The P1-A/P1-B controls, in a real browser. Fixtures are created by the test, never assumed from the developer's database. | [`browser_stage0_acceptance.mjs`](browser_stage0_acceptance.mjs) | Machine-readable Stage 0 baseline against an explicitly disposable daemon. Before reading a token it refuses port 8760, non-loopback or credential-bearing URLs, the default data directory, an `OPENAI4S_TOKEN` override, and any data-dir daemon state whose host, port, or pidfile does not match. Cross-origin HTTP, API, and WebSocket requests are blocked and counted; every execute-refusal probe is preceded by a frame kernel state of `repl_enabled=false`; and the Artifact link comes from the production completion projector plus production UI renderer. The summary carries only one-way hashes for its project/frame/Artifact identities. `finally` deletes that exact project, proves it is absent from the production project-list response, and requires the Artifact readback to return 404. It truthfully reports zero Agent requests while marking provider-call count as unobservable at this browser boundary. |
| [`browser_stage1_trusted_delivery.mjs`](browser_stage1_trusted_delivery.mjs) | One-command local browser acceptance for Stage 1 trusted delivery. It owns a random-loopback disposable daemon and metadata-only standard-readiness fixture, uses the production completion and stored-message renderers, and checks three passes over 100 exact-version links for HTTP 200 and SHA-256. It also proves same-head dedup retains the capture observation, delegated code/native producers reopen with their real child frame and no fabricated Notebook link, an old link stays immutable after a new head, zero Agent/LLM/external-network work occurs, and cleanup removes precisely its fixture. |
| [`browser_team_mode.mjs`](browser_team_mode.mjs) | Team mode as a *person* meets it, which is the half no socket-level test can see: the anonymous redirect to `/login`, the identity chip, the admin governance panel rendering live users/usage/quotas/invites/audit, a member refused that panel and not even shown its button, a guest invite redeeming into an account whose entire world is `/replay`, and the cross-user refusals (a non-participant's project, artifact bytes through `/preview/`). The only gate that needs its own daemon: `OPENAI4S_TEAM_MODE=1` plus two seeded accounts, whose passwords arrive in `OPENAI4S_TEAM_ADMIN_PW` / `OPENAI4S_TEAM_MEMBER_PW` because a password must not ride argv. |
| [`scientific_renderers_smoke.cjs`](scientific_renderers_smoke.cjs) | A dependency-light Node runner that checks the UMD scientific artifact parsers in the Web UI against their contract. Run by hand with `node tests/scientific_renderers_smoke.cjs`; no CI job invokes it. |

None of the `browser_*.mjs` files runs under `uv run pytest`; install the driver with `npm install --no-save --ignore-scripts playwright@1.54.1` and `npx playwright install <engine>`. Most need a separately started daemon. Stage 1 is the deliberate exception: `node tests/browser_stage1_trusted_delivery.mjs` owns its random-port disposable daemon and local fixture. The Stage 0 pack is intentionally stricter than the other externally managed browser probes: start a throwaway daemon with its own temporary `OPENAI4S_DATA_DIR`, `OPENAI4S_NOTEBOOK_REPL=0`, and a non-8760 loopback port, then run `env -u OPENAI4S_TOKEN OPENAI4S_BROWSER_DISPOSABLE=1 OPENAI4S_BROWSER_URL=http://127.0.0.1:<disposable-port>/ OPENAI4S_DATA_DIR=<same-temp-dir> node tests/browser_stage0_acceptance.mjs`; consume only its single `SUMMARY` line. The daemon must still own matching `daemon.json`, `openai4s.pid`, and owner-only `access-token` files in that directory. Its redaction/schema/binding/production-projection self-check is `OPENAI4S_STAGE0_SELF_TEST=1 node tests/browser_stage0_acceptance.mjs` and does not load Playwright or contact a daemon. CI runs the workbench walk, the admission-fault case and the P1 controls under Chromium — depth, not breadth — and [`browser_matrix.mjs`](browser_matrix.mjs) in all three engines.

## Test modules

Every `test_*.py` file is listed below, with the reason the module exists rather than an inventory of its cases. Most modules also carry extra regression cases around failure, restart, redaction, and concurrency that the line does not name.

| File | Why you would open this file |
| --- | --- |
| [`test_action_ledger_repository.py`](test_action_ledger_repository.py) | Four assertions about what the Ledger storage refuses to do: overwrite a group or an event, split an atomic tool group, or rewrite a terminal execution attempt. The column migration is additive. |
| [`test_action_ledger_runtime.py`](test_action_ledger_runtime.py) | The other half of the Ledger: what the running loop actually writes into it. Arguments are redacted before they land, a branch inherits only its checkpointed parent prefix, an interrupted native group is closed atomically, and the history rebuilds after the store is reopened. |
| [`test_action_routing_eval.py`](test_action_routing_eval.py) | Less an assertion suite than a scorer. It replays offline routing fixtures through the Tool/Code/Finalize router and emits a failure and confusion report for a human to review. |
| [`test_action_timeline_service.py`](test_action_timeline_service.py) | Open this when the Timeline shows a user something it should not. The projection is public, so the tests are mostly about what it withholds — raw payloads, secrets, provider IDs — and about what it must not withhold, such as an earlier tool failure. |
| [`test_actions.py`](test_actions.py) | Reply parsing, shared by both outer loops. The precedence rules are pinned here: a native call beats a code fence, an unclosed fence is never executable, and only the first Cell in document order runs. |
| [`test_admet_genetic.py`](test_admet_genetic.py) | The bundled ADMET genetic Skill: that it is discoverable, that its helpers aggregate deterministically, and that the dashboard it emits escapes script and HTML delimiters. |
| [`test_agent.py`](test_agent.py) | The broadest module in the suite — the offline outer loop end to end. Code-as-Action cycles, an R Cell that soft-fails into an observation when R is absent, token estimation, compaction that keeps a Cell and its observation in one atomic segment, and the delegation caps. A change that breaks the loop usually breaks here first. |
| [`test_agent_control.py`](test_agent_control.py) | Native tool batches under stress. Every call in a batch reaches a result even when one invocation fails or the turn is cancelled mid-batch. Independent read-only calls may run in parallel, but a mutating call is a barrier for everything after it. |
| [`test_agent_engine.py`](test_agent_engine.py) | `AgentEngine` on its own, driven through fake ports. The last test is the point of the module: the engine must not import runtime infrastructure. The rest pin routing precedence, replay-safe history grouping, and the exact moments at which cancellation wins. |
| [`test_agent_hybrid.py`](test_agent_hybrid.py) | Two tests on the hybrid `Agent` facade: a native call beats code and its canonical history survives into the next turn, and a reused agent clears the previous submission before a new task. |
| [`test_agent_profile_repository.py`](test_agent_profile_repository.py) | Named agent profiles in SQLite, mostly the awkward parts — legacy serialization of falsy values, JSON decoding edges in listings, and the read-then-write gap an upsert has to survive. |
| [`test_agent_runtime.py`](test_agent_runtime.py) | The local adapters between the pure engine and real infrastructure. Two rules dominate: a native parse error or a limit must never dispatch, and it must never drop a tool result either. Compaction expands its tail to keep an assistant tool group atomic, and a circuit breaker stops repeated low-yield compaction. |
| [`test_analysis_skills.py`](test_analysis_skills.py) | The bundled analysis Skills are executed here, not just listed. Their data audit catches group leakage, the AUC is tie-aware, and the bootstrap is deterministic. |
| [`test_annotation_repository.py`](test_annotation_repository.py) | Image annotations. Three tests, and the one that matters is ordinal allocation under concurrent pins — it has to be atomic. |
| [`test_artifact_control_tools.py`](test_artifact_control_tools.py) | Artifact restore is the dangerous operation, so most of this module is about refusing it: a corrupt snapshot, an untrusted ID, a workspace that drifted since the version was cut. Restore stays behind approval and rolls back a failed store write. |
| [`test_token_mint_atomicity.py`](test_token_mint_atomicity.py) | Whether two daemons starting together agree on the access token. The mint read the file, saw nothing, and finished with an *unconditional* `os.replace` — which never fails on a name already taken, so every racer won: each overwrote the file, and the re-read meant to adopt the winner's value sat outside any exclusion. Eight processes released at one barrier produced seven different tokens with only the last write on disk, so the surviving daemons authorised cookies against a value the CLI and the printed `?token=` URL could no longer read. The winner is now decided by `os.link` onto the final name — the one publish that can only succeed once — and the content is complete before that name exists, so a loser's re-read cannot land on a half-written file the way an `O_EXCL` create on the final path itself would allow. The file and its directory are both fsynced, because a published name that is not directory-fsynced can vanish on a crash while its bytes survive, and 0o600 is on the inode before the first byte of the secret rather than chmod-ed after it. The deciding test spawns real processes rather than threads: the gap is between two syscalls, which the GIL hands off anyway, so a threaded version would have passed against the broken code. |
| [`test_first_run_access.py`](test_first_run_access.py) | Whether a first-run user can get into their own daemon. The access token became required by default — correct, this daemon executes code — and nothing that hands a URL to a human was updated: `_url()` returned the bare origin and fed the browser auto-open, `status`, `url`, and the macOS .app. Every recovery path was closed too: `/static/app.js` is behind the same gate so the SPA cannot load and cannot offer a way in, the 401 body was JSON, and the one working URL goes to stderr which the .app redirects into a log file. A .dmg user had no in-product route to a working session. Now the printed URL carries the token (and machine callers that append paths opt out, or they build `...?token=Xhealth`), and an unauthorised *browser navigation* gets an HTML page naming the command to run while scripts still get parseable JSON. The page embeds no credential and fetches nothing, since every asset it could reference is behind the same gate. |
| [`test_token_query_bootstrap.py`](test_token_query_bootstrap.py) | How the access token is allowed to travel, driven through the real `Handler`. The `?token=` bootstrap was written as a subtraction — anything that is not `/api/v1/*` or `/static/*` — and described in its own comment as "paths that serve the SPA shell". `/preview/<id>` is neither: it answers with artifact bytes, so a link carrying a token there set a durable `HttpOnly` cookie for the whole daemon and then served the file to whoever held the link, which is the exact leak the restriction existed to prevent. The rule is now an allowlist of the root page, the only URL the product ever prints. Separately, a `token` in the query string of a mutation was merely *not used* to authenticate: a request that also carried a valid cookie succeeded with the credential still in its URL, so the caller had no way to discover they were shipping a secret — it is refused outright now. The rest pins what must not break: the 303's `Location` carries no credential, the cookie is `HttpOnly; SameSite=Strict; Path=/`, `/health` stays open, and `Authorization: Bearer` still authenticates. |
| [`test_frame_cap_units.py`](test_frame_cap_units.py) | Two caps that measured different things, and a refusal one tool skipped. `MAX_OUTPUT` caps stdout and stderr at 1,000,000 *characters*; `_MAX_FRAME_BYTES` capped the frame at 8,000,000 *bytes* with a comment claiming it sat above the largest legitimate frame — true only for ASCII. Measured at the documented caps: ascii 2,000,059 bytes (ok), CJK and control 12,000,059 (dropped), emoji 24,000,059. A cell obeying every documented limit lost stderr, the exception text, `error_lineno`, `guards` and `usage`; only stdout survived, and only via the manager's chunk backfill. The cap is now derived from `MAX_OUTPUT` so the two cannot drift apart again — and the derivation's first constant was wrong (6, for `\uXXXX`) because Python counts an astral character as one while JSON emits a twelve-byte surrogate pair; a test here caught that. Separately, `secret_path_key` is the hard refusal that stops a tool overwriting a credential file, `write_file` and `edit_file` declared it and `web_download` — the only other tool with `writes_files` — did not, so `write_file(".env")` was refused while `web_download(url, ".env")` was not. Asserted over *every* file-writing tool, so a fourth cannot be added without it. |
| [`test_message_paging_client.py`](test_message_paging_client.py) | Which end of a long conversation the workbench opens on. `newest_first`, `before_seq`, `next_before_seq` and `has_earlier` were built through the store, the repository and the route; `app.js` contained neither `newest_first` nor `before_seq`, and all four message fetches sent `?from=0&limit=300\|500` — the OLDEST page. A 640-message session opened on messages 0–299 and the work you came back for was off the end, while `gateway.py` carried a comment describing "the client asks for the newest page" — describing a client nobody had written. All four call sites now go through one helper, which also sorts the descending rows back into reading order (rendering them raw would show the conversation backwards, a worse bug that looks like a server fault). Records honestly that `has_earlier`/`next_before_seq` are still unread, so a session longer than one page still has unreachable older messages — it now hides the old ones rather than the recent ones. |
| [`test_model_binding_recovery.py`](test_model_binding_recovery.py) | Whether a session pinned to a model configuration can ever be sent to again. D2's 409 `model_revision_unavailable` — "choose one to continue" — was correct and unanswerable: both writers of `model_profile_id` sit past the raise, `PATCH /frames/{id}` allowlists name and task_summary, forking inherits the pin, ids are random so re-creating the profile does not match, and `app.js` had zero references to the code. Deleting a model profile permanently bricked every session bound to it — history and artifacts readable, never sendable again. Two triggers, only one involving a delete click; the other is a profile that exists whose bound *revision* does not. Now delete releases what pointed at it, and `POST /frames/{id}/model-binding` answers the rest. Deliberately its own route rather than a flag on send: the client sends `model` on every message, so treating that as consent would re-pin silently on every turn — the drift D2 removed. The 409 itself is unchanged and a test fails if it is softened. |
| [`test_retrieval_provenance.py`](test_retrieval_provenance.py) | A retrieved record says when it was fetched and hashes what upstream returned, so a rerun that quietly changed is distinguishable from one that did not — and that envelope reaches the artifact derived from it. |
| [`test_artifact_env_provenance.py`](test_artifact_env_provenance.py) | An artifact records the environment that produced it: an R cell's artifact stops carrying a Python package list, a selected conda env is named rather than the daemon's, and an unreadable interpreter reports absence instead of borrowing this process's packages. |
| [`test_response_schemas.py`](test_response_schemas.py) | The HTTP surface has a shape that can be checked. Response shapes are captured from real responses rather than written by hand, so the frozen file cannot describe a response the code does not produce; the tests pin the shape algebra (an optional field must not stay required, an observed null makes a field nullable rather than optional) and the distinction the gate exists to make — a removed guarantee is BREAKING, a new field is additive. |
| [`test_response_capture_assembly.py`](test_response_capture_assembly.py) | The capture survives being split across xdist workers. Workers atomically publish during `pytest_sessionfinish`, before xdist reports success, and every share names the run plus expected worker count. Assembly rejects missing, corrupt, stale, or mixed-run evidence before writing; a complete split must equal the single-process schema even for nullable numeric and optional-field observations. |
| [`test_server_errors_module.py`](test_server_errors_module.py) | The HTTP failure type is importable without importing the gateway. A prerequisite for decomposing `Handler._api`, not tidying: `GatewayError` sat ~5,800 lines below gateway's own imports, so a route module importing it from there failed the daemon at boot. Pins the no-cycle property in a fresh interpreter and the re-exported names ten test modules already use. |
| [`test_followup_admission.py`](test_followup_admission.py) | What a session accepts while a turn is already running. A message had no text limit at all — the only bound was `_MAX_JSON_BODY_BYTES`, the *session archive* cap of 128 MiB standing in as a chat-message cap — and the message is persisted and replayed, so an 8 MiB paste is eight times the whole context window on its own and compaction cannot rescue it, because summarising it means sending it. A session pinned to a deleted model revision was refused with 409 *inside the worker thread*, so over HTTP it arrived as **200** with `{"status": "failed"}`, the same soft-dictionary shape six other routes were fixed for. A full queue reached the client as **500 internal_error**, telling a retrying client to loop against a queue that cannot accept anything until the user acts. Everything here drives the real handler: each defect lived in the gap between a function that behaved correctly and the route that reported it. |
| [`test_gateway_kernel_routes.py`](test_gateway_kernel_routes.py) | The twelve kernel routes, pinned before they are moved out of `Handler._api`. Four had no frozen shape and no route-level test at all; four more had only their 403 "REPL disabled" envelope pinned, so swapping the restart and stop bodies passed pytest, the response-shape gate, and the browser smoke run together. Also records two asymmetries as-is rather than tidying them: ten of the twelve answer 200 for an unknown frame id, and `kernel/install` is deliberately ungated by `notebook_repl`. Marked `stubbed_backend` where a service is replaced, so the fabricated responses never reach the frozen contract. |
| [`test_telemetry_schema.py`](test_telemetry_schema.py) | Telemetry may say counts and enumerations, and this is what stops it saying more. Attacks **values**, not keys — `{"error_type": "ValueError"}` and `{"error_type": "FileNotFoundError: /home/y/unpublished/cohort.csv"}` pass the same key check. The leak shapes are taken from what this repo really produces (an exception class defined inside an agent-authored cell, a skill name from SKILL.md frontmatter, an environment directory name, a provider error sentence), crossed against every declared field. Also asserts the package never imports the credential redactor, which exempts absolute paths on purpose. |
| [`test_egress_surface.py`](test_egress_surface.py) | Every module that can open an outbound connection is declared, with a reason. Written as a prerequisite for telemetry but not about it: before this, nothing recorded which modules can reach the network, and "not a single packet leaves the machine" is a claim about the whole tree that cannot be checked one file at a time. Seven modules today. A new one fails with its file and line, so adding a line to the table is a decision while adding `urlopen` to a module is a Tuesday. Listening sockets are deliberately out of scope — a different risk with a different answer. |
| [`test_telemetry_consent.py`](test_telemetry_consent.py) | Consent is what telemetry may not work without. Pins the two properties whose reasonable-looking alternatives fail quietly: revoke destroys the install id along with the permission (and leaves no tombstone, since a record that a grant once existed is itself a fact outliving its withdrawal), and an environment variable can veto but never grant. Writing it found a real defect — a vetoed `grant()` still wrote the row, so a scripted grant landed silently and would take effect the moment the variable went away. |
| [`test_telemetry_off_by_default.py`](test_telemetry_off_by_default.py) | The proof that with no consent nothing leaves the machine. | [`test_telemetry_emit.py`](test_telemetry_emit.py) | `emit` sits on hot paths (daemon start, end of every turn), so its first duty is to do no harm: a store that raises, a consent read that throws, a send that crashes — none may reach the caller, and the send never runs on the caller's thread. | [`test_telemetry_transmission.py`](test_telemetry_transmission.py) | Revocation as a boundary rather than a request to stop soon: a barrier steps a sender to the exact point between the consent read and the socket open, then revokes from another thread, and the invariant is one comparison — nothing reached the opener after `revoke` returned. | [`test_telemetry_consent_route.py`](test_telemetry_consent_route.py) | The Customize toggle at the HTTP boundary. | [`test_telemetry_collector.py`](test_telemetry_collector.py) | The receiving end, exercised on an ephemeral loopback port (never a public bind) with the same `wire.seal` the client uses. | [`test_artifact_manager.py`](test_artifact_manager.py) | Workspace Artifact capture, versioning, and cell promotion. ## Choosing the right place

Put a focused regression assertion here. Put reusable scripted scenarios, fake providers, normalized trajectories, scored evaluations, and reviewed goldens in the [`../harness/`](../harness/) layer. Default tests in both layers stay offline unless their entry point is explicitly marked and invoked as an opt-in smoke.
