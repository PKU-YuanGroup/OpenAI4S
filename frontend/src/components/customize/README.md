# frontend/src/components/customize

[中文说明](README_zh.md)

F-19 Customize modal. Eleven tabs, a nested editor overlay, and `vendors/` cards. Class names (`#cust`, `.cust-tab`, `.prof-row`, `.cust-row`, `.toggle`) match the E2E contract. Tab unmount disposes the timer lease.

## Files

| File | Responsibility |
| --- | --- |
| [`ComputeTab.tsx`](ComputeTab.tsx) | Compute, remote GPU, jobs. Shows what Python and R run in for the open session (or the defaults): environment name, kind (built-in / managed / local) and version, plus whether R's key packages load, read from `runtimes` on the environment listing. The tracked-package row lists installed versions and what is missing. An install's outcome stays on screen: the version installed, the environment it went into and what a running kernel must do. One job poll chain, 1500ms on the lease; a newer read supersedes an older one. The readiness card is onboarding's `EnvironmentCard`; the status comes from send's `refreshEnvironmentStatus`. |
| [`ComputeTab.test.tsx`](ComputeTab.test.tsx) | The Python and R rows name environment, kind and version and say which R packages load; the package row carries versions; an install's result (with version) and a failed install's reason stay on screen. Submit and Cancel re-read the job list without starting a second poll chain; an older read that answers late is dropped. |
| [`ConnectorsTab.tsx`](ConnectorsTab.tsx) | Connector list; DataPro card is isolated in `vendors/`. |
| [`Customize.tsx`](Customize.tsx) | `#cust` shell, tablist, Esc / backdrop close, and the status line under the tab body that repeats what the last action reported (`customizeNotice`; `hint()` alone writes under the composer, behind the modal). |

| [`UpdateCheck.tsx`](UpdateCheck.tsx) | U2 "Version and updates" row over appendix B.2: mount reads only the local `GET /updates/status`; "Check for updates" posts `{refresh:false}` and "Force a fresh check" `{refresh:true}`. It shows the running/latest version, channel, cache age, check time, the two-word trust summary (authorship always "not verified") and, for `unknown`, the reason code plus the last known answer with its time; only `up_to_date` says "this is the latest version". Channel refusal commands are copyable text and are never executed — there is no download, install, restart, one-click upgrade or polling. |

| [`DiagnosticsTab.tsx`](DiagnosticsTab.tsx) | Passive security posture, explicit checks, and redacted support-bundle download. The Diagnostics page, above the update row. |

The add form's Model field takes suggestions from "Fetch model list" (`POST /model-profiles/discover`, the wizard's list) and still accepts any id. With no active profile it shows the live `GET /config/llm` model (environment or saved settings) as the active row. | [`NetworkTab.tsx`](NetworkTab.tsx) | Doubao card, allowlist, Tavily backup, telemetry drain. The allowlist section says what the domain groups are and whether they apply (`egress_mode` off vs `allowlist`), gives the exact restart command for the other mode with a copy button (`egressRestartCommand`; the mode is read at start, there is no runtime switch), lists approved domains, names the groups in the UI language (`allowlistGroupName`), and counts the domains past the first twelve instead of cutting them silently. The header and switch speak of app networking (the agent's web search, web pages, science databases and downloads; the model service is not affected) and of kernel networking (code in cells, blocked by the sandbox by default, which nothing on this tab opens). A team member gets the state read-only: no Ollama / Doubao key cards, switches locked with the reason. |
| [`PermissionsTab.tsx`](PermissionsTab.tsx) | Per-scope approval rules. With no session open it reads `GET /permissions` and lists the global rules alone. Each rule says what its tool does, and the summary under the title is read from the global rules. A rule's decision is optimistic and goes back when the server refuses it. A team member sees the global tier locked and Restore defaults disabled, each with the reason. |
| [`SearchEngines.tsx`](SearchEngines.tsx) | Network tab's search-engine order: Doubao pinned on top, backups reorderable (drag or arrows) and switchable, Tavily / You.com keys; `readOnly` shows the list without key fields or changes. |
| [`PermissionsTab.test.tsx`](PermissionsTab.test.tsx) | A decision the server took stays shown; a refused one goes back to the rule's decision (a render is asked for, so the select resets). | [`refresh.test.tsx`](refresh.test.tsx) | A write that answers after the user moved to another tab, or opened another nested editor, leaves them where they are; a write on the tab still shown re-reads it in place without remounting it. |
| [`SkillsTab.tsx`](SkillsTab.tsx) | Personal / project / collection skills. A search box ranks every skill, collection members included, the way the `/` picker does (name, description, Chinese keyword, declared domain); a `host_only` skill is marked with the number of domains it limits a session to and lists them on expand. |
| [`SkillsTab.test.tsx`](SkillsTab.test.tsx) | Skills-tab search finds a skill by name, description word, Chinese keyword or declared domain, reaches collection members, and finds nothing for a miss; only a `host_only` skill gets a network-limit badge. |
