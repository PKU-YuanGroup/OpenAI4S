# 筛选前的窗口审查

[English](README.md)

这个离线扩展实际调用面板 Skill 的 `assess_windows`，区分“完整观测够用”与“能够判断波动的基线够用”。使用既有公开输入，不插补、不筛选事件，也不更改 DiD 估计或之前的结果。每一个已观测实体—时期都可作为事后窗口首期的**审查锚点**；以下计数是日历位置，并非处理日期或检出的事件。

## 运行与文件

从仓库根目录运行，使用包含 matplotlib 的 Python 环境输出图形：

```bash
MPLCONFIGDIR=/tmp/openai4s-window-mpl python experiments/did-arxiv-replication/window-review/run_review.py --output /tmp/window-review-new
```

程序首先按 `../inputs/sources.json` 核对公开 CSV 的哈希，再导入实际 Skill sidecar，并拒绝覆盖自身已有产物。正常运行无需联网。`environment.json` 记录库版本与代码／产物哈希；图像字节一致还取决于运行环境及字体。

| 文件 | 用途 |
| --- | --- |
| `run_review.py` | 可重跑的公开面板审计和明确标注的构造示例；可选绘图库导入有保护。 |
| `synthetic.csv` | 保存三条确定性序列、共 96 行的构造示例；没有嵌入处理或事件。 |
| `audit.json` | 配置、覆盖计数、波动状态计数、按确定顺序保存的代表性评估／建议，以及合成数据固定锚点详情。 |
| `comparison.png` | 四联图展示数据覆盖、波动状态、构造轨迹及有条件的窗口建议。 |
| `comparison.svg` | 同一图形的矢量版本。 |
| `environment.json` | Python／matplotlib 版本与脚本、Skill、产物哈希。 |

每个锚点的完整 API 评估都可由保留的数据和脚本重新生成。保存的审计保留汇总与每一种合格状态／建议的首个示例，避免复制数千条详细记录。

## 固定诊断假设

公开输入和许可保留在 `../inputs/`；审计再次记录来源 URL 和哈希。对 mpdta 比较两期与三期窗口，容许波动设为 **0.05 个 log 就业单位**；对 base_stagg 比较三期与五期窗口，设为 **1 个结果单位**。这些是明确声明的诊断假设，并非论文规定的阈值。完整事前窗口短于五期时，定量噪声建议会标注基线过短。

图中的 `SD / sqrt(n)` 仅在噪声稳定、独立的假设下描述均值波动。仍保留原始样本方差／SD、MAD、拟合斜率、残差 SD，以及基线足够长时的一阶相关性诊断。趋势或相关性审查优先于直接的噪声解释。窗口建议只供审查，不自动更改请求的筛选配置。增加窗口不能保证较小方差、检出能力、误差独立或因果有效性；较早冲击、漂移和季节性可能污染更宽的窗口。

## 公开数据发现

| 输入／窗口 | 完整审查锚点 | 完整锚点中的波动状态 |
| --- | --- | --- |
| mpdta／2 | 1,000 / 2,500 | 1,000 个均为事前基线过短。 |
| mpdta／3 | 0 / 2,500 | 五个年度无法容纳两个三期窗口。 |
| base_stagg／3 | 475 / 950 | 371 个短基线；104 个需要趋势审查。 |
| base_stagg／5 | 95 / 950 | 33 个在 IID 假设下噪声偏高；60 个在容许范围内；2 个需要趋势审查。 |

把公开模拟数据的窗口从三期扩大至五期，可用锚点从 475 个降至 95 个。图中均值波动近似的总体中位数从 1.001 降为 0.909 单位，但比较的是不同锚点集合，**不能**据此证明扩大窗口改善了某个事件筛选。API 的建议只比较同一锚点。真实面板根本无法提供完整的前后五期基线；任何定量窗口建议都不能补出不存在的历史数据。

## 构造示例

三条 32 期序列以 10 为基准，重复保存的显式波动 `[-1.3, 0.7, 0.4, -0.9, 1.1]`：quiet 与 trend 使用 0.04 倍幅度，noisy 使用 1.1 倍幅度，trend 另加每期 0.35 的漂移。这些确定性周期序列用于展示建议逻辑的不同分支，并非 IID 模拟或实证验证。固定审查锚点为第 17 期，请求窗口为五期，检查 3／5／7 期，容许波动为 0.5 个结果单位。

在这个固定锚点，noisy 序列展示的近似量在五期时为 0.514 单位，七期时为 0.457，因此 API 有条件地建议考虑七期。quiet 保留五期（0.019 单位）；trend 要求审查趋势，而非扩大窗口。三条序列都具备所检查窗口需要的观测，但得到的建议不同。没有使用这些结果选择事件筛选、处理日期或因果估计。
