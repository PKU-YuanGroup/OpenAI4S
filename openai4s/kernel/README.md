# Kernel runtime

[中文说明](README_zh.md)

The persistent Python and R kernels live here, and with them the system's scientific execution plane. The outer agent loop hands this package at most one complete Cell at a time; the worker starts on first use, speaks a language-neutral JSON-lines protocol, and keeps its namespace alive across Cells. The inner synchronous Host RPC loop is Python-only.

## Where this fits

1. [`agent/engine.py`](../agent/engine.py) routes a Cell action without depending on any concrete kernel.
2. CLI and Web composition create a lazy [`Kernel`](manager.py) or a supervised Python/R slot.
3. The manager sends one `execute` frame. A Python worker may answer with `host_call`; the manager dispatches it and writes back the matching `host_response` before it goes on waiting for the Cell's final response. Compatibility acknowledgements are not the normal completion path.
4. The worker returns captured output, error and interrupt details, guard reports, and resource usage. Namespace inspection is a separate bounded request, not a synthetic Cell. A Cell result becomes another outer-loop observation; only Python `host.submit_output(...)` can complete a task from inside a Cell.

For each worker, the manager must be the only party that reads frames. The worker's protocol-write lock serializes frames on the wire, and its Host-call transaction lock allows only one synchronous RPC in flight at a time. The Web execution coordinator and [`KernelSupervisor`](supervisor.py) coordinate writers and lifecycle around that protocol; neither proxies it.

## Files

| File | Responsibility |
| --- | --- |
| [`__init__.py`](__init__.py) | Public exports for `Kernel`, `KernelBusyError`, `KernelLease`, and `KernelSupervisor`. |
| [`background.py`](background.py) | The home of `host.exec_background`. A Cell that will run for a long time — a training run, a long simulation — gets a worker process of its own, so it never blocks the foreground kernel or the agent's turn. `exec_peek` reads its accumulated stdout without waiting; `exec_interrupt` sends one idempotent SIGINT. Such a job cannot see the foreground namespace, and nothing about it is written to disk. What it accumulates is bounded on both axes: the peek buffer keeps a head of `MAX_PEEK_CHARS` and marks the cut instead of growing for the life of the job, and sixteen jobs may run at once — each owns a subprocess, so that cap counts processes, and the slot is claimed before the spawn rather than registered after it, since a check that runs afterwards is one that concurrent launches all clear together and every one of them spawns. |
| [`errors.py`](errors.py) | The kernel's exception types, in a module that imports nothing. `KernelInterruptUnavailable` has to be catchable by `supervisor`, and `manager` reaches `supervisor` through the watchdog — so defining it in `manager` closed an import cycle that only failed on the orders where `manager` happened to be initialised first. `manager` re-exports both names, so existing imports keep working. |
| [`environment.py`](environment.py) | Decides what a kernel is allowed to inherit. The child environment is built from a small explicit allowlist rather than copied from `os.environ`, so provider keys, cloud tokens, agent sockets, and loader-injection variables stop at the process boundary. Anything a Cell then launches, `host.bash` included, inherits that same filtered mapping. |
| [`environments.py`](environments.py) | Environment selection: how a task moves to an interpreter that already has what it needs instead of installing packages every time. Prebuilt conda environments are discovered under `OPENAI4S_ENV_ROOTS` or the usual install roots, probed for `bin/python` or `bin/Rscript`, and cached with their package sets. The daemon's own interpreter is always offered as a synthetic `base` environment, so a selection can never leave a session with no Python kernel. |
| [`errors.py`](errors.py) | Leaf exception definitions shared by the manager and supervisor. Keeping busy and interrupt-unavailable errors here avoids an import cycle while preserving the distinction between a transient interrupt failure and a remote kernel that has no signal path at all. |
| [`guards.py`](guards.py) | Looks for state that leaks from one Cell into the next: pyplot figures a Cell opened and never closed, plus a few process-global registries pinned before the Cell and diffed after. These are cheap probes, not confinement. A probe whose optional library is missing does nothing, and `OPENAI4S_GUARDS_OFF=1` turns the whole bundle off. |
| [`lazy.py`](lazy.py) | Keeps a turn that only calls tools or only finalizes from starting an interpreter it never needs. One owner, one start, thread-safe. The candidate worker is published early enough that a cancellation can still reach it, and a failed bootstrap is detached and shut down rather than reused. |
| [`manager.py`](manager.py) | The host side of one worker. It spawns the subprocess, wraps the command in the OS sandbox, and is the only party that ever reads that worker's JSON-lines frames. One `execute` frame goes out; what comes back may be a streamed output chunk, the final response, or a `host_call` that has to be answered with a `host_response` before the blocked Cell can go on. Interrupts and restart generations are driven from here. The worker's stderr is drained by a thread of its own and bounded in bytes *at the read* — `os.read` on the descriptor underneath the text decoder, since the pipe is opened in text mode for the protocol frames — and it reports what it saw, kept and dropped, so the tail printed when a worker dies is not read as the whole of the failure. |
| [`preinstall.py`](preinstall.py) | Package management for the kernel, held at arm's length: it is support tooling, and the stdlib core never takes a hard import dependency on it. Startup only ever *reports* what the scientific baseline is missing; applying that plan is a separate act a human or an explicit API asks for. `serve` used to apply it itself, on a background thread, resolving ~23 unpinned names against PyPI and installing them with `--break-system-packages` — so launching the daemon mutated the user's interpreter, two cold starts a week apart disagreed, and an offline one failed where nobody was watching. A newly installed package only reaches a fresh process, so restarting the kernel afterwards is the caller's job. It also owns the confined probe every foreign interpreter runs under, and `freeze_for`, which reads a package list from one named interpreter and returns nothing rather than falling back to this process's own — an artifact's environment provenance is attributed from that. |
| [`protocol.py`](protocol.py) | The shared byte ceiling for one JSON-lines frame. The worker producer and the remote socket receiver import the same value, so a response admitted at one end cannot be rejected as oversized at the other. |
| [`provenance.py`](provenance.py) | Installs object-level lineage instrumentation inside the Python worker. Objects read through a supported reader carry the source `version_id` of the artifact they came from, and a later write reports the input versions they accumulated. It sees what it can see, not everything. The side table that holds tags for objects which cannot carry an attribute stores the object next to its id: an id is not an identity, CPython reuses a freed address immediately, and an unrelated object was inheriting the lineage of whatever used to live there. That table is bounded and evicts oldest-first, which loses a tag rather than inventing one. |
| [`r_kernel.py`](r_kernel.py) | Resolves a real `Rscript` and builds the file-descriptor-safe command that runs the R sibling through the common manager. Python is never silently substituted. |
| [`r_worker.R`](r_worker.R) | The persistent R worker, holding the same execute/response contract as Python: captured output, interruption, the failing line and call, resource usage. A Cell's two streams are sunk to the host's fifos with `blocking = TRUE` — R's `fifo()` defaults to non-blocking and silently drops whatever will not fit the pipe buffer — so the host's reader paces the Cell and its output arrives live instead of all at the end; the response sets `sink_capture` to say the host, not the worker, is holding it. Output is still flushed between top-level expressions, for the expression that ends without filling that buffer. Inbound frames are parsed with `jsonlite`, but outbound JSON is escaped by hand, so an R install without `jsonlite` still reports a clean structured error instead of dying. It is an analysis channel: no `host` object, no mid-Cell RPC, no way to complete a task from inside a Cell. |
| [`readiness.py`](readiness.py) | The Stage 1 local-only readiness projection for the `standard` pair. It parses the shipped direct Python/R dependency lists, compares them with discovered local package metadata, and returns a path-free `ready`/`needs_setup`/`needs_repair`/`unavailable` DTO plus explicit managed repair commands. The check starts no interpreter, imports no science package, contacts no network, and mutates nothing; an unreadable inventory fails closed rather than pretending every package is missing or installed. |
| [`recovery.py`](recovery.py) | Builds a replacement kernel from a content-addressed, canonical bootstrap recipe plus conservatively classified replay steps, and validates it before anyone else sees it. The candidate is published only once validation passes, and recovery reports `partial` when state cannot be safely reconstructed. |
| [`env_generations.py`](env_generations.py) | An environment change as a transaction: `plan` touches nothing, `apply` builds a *new* generation and only then moves the `current` pointer, a failed apply leaves the previous environment exactly as it was, and `rollback` is a pointer move to a generation still on disk. The generation is built at its final prefix — Conda bakes absolute paths in, so a renamed staging directory is a broken environment — and what is made atomic is its *visibility* instead. The id that names one is confined to its own environment, because it is joined onto a path and read back by every later kernel spawn. Stage 1's explicit `--repair` forces a fresh generation even when the spec hash is unchanged; Python/R standard generations must start their real interpreter and contain every direct manifest package before the pointer may move. |
| [`sink_drain.py`](sink_drain.py) | Bounds a worker's captured output from the host end, for a worker that cannot bound it from its own. R is single threaded and no callback fires inside a top-level expression, so a cap living in the R worker could only act *between* expressions — one expression printing 300 MB still wrote all of it to a tempfile that is a tmpfs on much of Linux. Here the cell's two streams go to fifos this module drains: it keeps the first megabyte, discards the rest as it arrives, and reports exactly how many bytes it saw and dropped, so a capped result cannot be confused with output that was silently lost. It reports the *fact* too — `stdout_truncated` / `stderr_truncated` — rather than leaving a consumer to derive it: output ending exactly at the cap was never cut, and a cell whose own text happens to contain the marker's wording is evidence of nothing. The retained head is handed on incrementally as it lands, which is what makes an R cell's output live. |
| [`supervisor.py`](supervisor.py) | Owns the durable Python and R session slots, and stops there. A caller receives a lease naming the exact generation it acted on, and interrupt, restart, and watchdog replacement only fire while that lease still matches the live slot — so a late caller cannot kill the kernel that already replaced the one it meant. It never reads a protocol frame. |
| [`transport.py`](transport.py) | How a Kernel reaches its worker: `PipeTransport` for the local child (moved rather than rewritten — the Popen call, the stderr drain thread and the shutdown sequence each record a failure already paid for once: a filled stderr pipe deadlocking a cell, a daemon thread parked in a buffered read turning a clean exit into SIGABRT, a restart leaking a zombie), and `OutboundTcpTransport` for a worker that dialled in from a compute node. The manager's protocol discipline is untouched by this file — one frame reader, id-routed `host_response`, the host-call transaction lock — because only *how bytes get to the other end* differs. Interrupt is the one operation that does not survive the move: there is no local pid across a cluster, so the remote transport takes an explicit hook and reports honestly when it has none, rather than returning success for a signal nobody sent. |
| [`worker.py`](worker.py) | The persistent Python worker, and the file that has to get the fiddly parts right. The protocol file descriptors are moved off stdout, so a stray print from Cell code lands on stderr instead of corrupting the wire. `host` is injected into the namespace and held to one Host-call transaction at a time. Cell source is registered with `linecache`, so a traceback points at the line the researcher actually wrote. SIGINT handling, guards, the audit hook, provenance, and the bounded inspection and usage replies are all armed here. Outbound frames are bounded at the producer, in three layers that each catch what the one before cannot: a `write()` streams in 64k chunks, a Cell's captured stream stops retaining at `MAX_OUTPUT` and says so with exactly one marker, and a frame still over the byte ceiling is replaced rather than truncated — a cut JSON line is not a frame, and the host's single reader would desynchronise on it. A dropped `response` keeps its type and id and carries the reason, because a frame the host is blocked waiting for that simply never arrives is a hang, not a refusal. |

## Security and failure boundaries

- Environment filtering, the pre-execution classifier, the OS sandbox, the in-worker audit hook, durable approval, and the one-shot shell capability are independent layers. One of them being in place says nothing about whether the others succeeded.
- [`manager.py`](manager.py) wraps the worker with [`security/sandbox.py`](../security/sandbox.py). `enforce` fails closed when confinement is unavailable; single-user `auto` may keep running after the real self-test fails, with a visible degraded or unavailable status. A team read policy is mandatory even under `auto` and refuses `off` or degradation. It masks daemon data, other users' personal data-root areas and stale system temp, while exact read-only exceptions preserve the source checkout, selected Python/R runtime, authorized sidecars and session Artifact inputs. That is managed-data isolation, not a claim that arbitrary same-UID host files are unreadable.
- Python code is deliberately powerful inside the workspace it was granted. [`environment.py`](environment.py) prevents inheritance of recognized secrets, but it cannot make arbitrary Cell code trustworthy.
- The R worker parses inbound requests with `jsonlite`. Without that package it emits a structured error, and it stays analysis-only either way. R Cells go through the same pre-execution classifier Python Cells do, and its loader vocabulary now names `dyn.load` and `library.dynam`: whether a multi-step loader escape was screened at all used to depend on which kernel the Cell asked for.
- Background execution gets a dedicated worker, and its job registry plus the output it accumulated live in process memory. Both are bounded now — sixteen running jobs, a capped peek buffer — but neither is durable: a daemon restart loses every background job along with everything it had printed.
- Provenance and guards are observational, and they do their best rather than guarantee coverage. Unsupported objects, unsupported libraries, native transformations, or an explicit opt-out can leave lineage incomplete.
- Recovery does not serialize a live Python or R namespace. It builds a new generation, replays only the steps it conservatively accepted, validates manifests, and will truthfully return partial recovery.
- Supervisor interrupt and restart calls must carry the exact lease and go through the session execution barrier. Bypassing those ownership rules races the manager's single frame reader.
