# Experiments

[中文说明](README_zh.md)

Research experiments with separate source data, executable code, results and explicit reproduction scope. These are local research artifacts, outside the production import graph and the bundled Skill package.

## Contents

- `did-arxiv-replication/`: two arXiv DiD methods checked against official public examples, using the panel-data-preprocessing Skill. See [the experiment](did-arxiv-replication/README.md).
- `panel-cleaning-synthetic/`: fixed-seed random panels testing fit-only cleaning, encoding, window readiness and visual event discovery against a separately retained generation truth. See [the experiment](panel-cleaning-synthetic/README.md).
- `did-skill-validation/`: Prespecified synthetic DiD, placebo, event-study and derivative analyses with independent cluster-inference comparisons and repeated fixed-seed simulations. [the experiment](did-skill-validation/README.md).
